🌍 Final Space App

An interactive 3D visualization of Earth and Near-Earth Objects (NEOs) built with Three.js.
The app allows users to explore space objects in real time with smooth animations and a clean interface.

🔗 Live Demo: [Space App](https://sohairateeq.github.io/Final-Space-App/Space%20app/index.html)
✨ Features

🌍 Realistic 3D model of Earth with rotation.

☄️ Display of Near-Earth Objects (NEOs) orbiting around Earth.

🎨 Built using Three.js for WebGL-powered rendering.

📱 Fully interactive and works directly in the browser (no installation needed).

🚀 Technologies Used

Three.js → 3D rendering engine.

JavaScript (ES6) → core logic and interactivity.

HTML5 / CSS3 → structure and styling.
